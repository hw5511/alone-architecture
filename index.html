② 단계별 설명 (사용자 관점)

  1. ① 메시지 입력 — 우희 사마가 woohee.store 채팅창에 자연어 지시
  2. ② SSE 스트림 — Chainlit 이 메시지를 AGI 도메인으로 전달
  3. ③ parent INSERT — AGI codex 가 parent 이슈를 SQLite 에 저장 (goal + complete_condition)
  4. ④ 60초 polling — alone-pm PM2 데몬이 새 parent 이슈 발견
  5. ⑤ run_session — 3단 orchestrator 진입 (split → workers → review)
  6. ⑥ Planner (split) — codex --output-schema 로 sub-issue 계약들 생성
  7. ⑦ Worker (run) — sub-issue 1건씩 bypass codex 가 실제 작업
  8. ⑧ 파일 write — workspace 안에 실제 산출물 생성
  9. ⑨ Review 진입 — 모든 sub 종료 → enforcement coordinator 호출
  10. ⑩ Evaluator 호출 — 독립 평가자 codex (NeurIPS 2024 self-preference 해소)
  11. ⑪ Final verdict — evaluator + mechanical (8종 mismatch) 합성 → accept/partial/reject
  12. ⑫ agi_inbox INSERT — escalation invariant: PM 채널 직통 X, agi_inbox 만
  13. ⑬ inbox_watcher — 3초 폴링이 새 inbox 항목 감지
  14. ⑭ AGI 주입 — PM 결과를 AGI 다음 응답 컨텍스트에 자동 prepend
  15. ⑮ 응답 생성 — AGI 가 결과를 종합해 우희 사마용 메시지 작성
  16. ⑯ emit 게이트 — actor='agi' 검증 (EscalationViolation 방지)
  17. ⑰ SSE 응답 — 우희 사마 브라우저로 스트림
